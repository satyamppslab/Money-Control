# Money Control

A personal finance application featuring transaction tracking, user authentication, and Gemini AI-powered receipt OCR scanning.

## Tech Stack
- **Frontend**: React, Vite, TailwindCSS, Axios, React Router
- **Backend**: Node.js, Express, MongoDB, Mongoose, JWT, Multer, Google Gemini AI SDK
